## Automated source and packaging gates

- Final clean `npm ci` from `package-lock.json`: passed; 664 packages installed.
- `npm run audit:prod`: passed with zero vulnerabilities after updating
  `@xmldom/xmldom` from the vulnerable 0.9.10 resolution to 0.9.12. Later
  production-audit retries were affected by intermittent npm bulk-audit
  failures and a rejected retired quick-audit fallback; the runtime dependency
  versions did not change after the successful result.
- `npm run audit:all`: completed with 28 development, Electron-runtime, and
  packaging-tree vulnerabilities (3 low, 24 high, 1 critical).
- Compatible non-force remediation updated `@xmldom/xmldom`, `browserslist`,
  `fast-uri`, `ip-address`, and `nanoid`. The patched Electron 41 release
  requires Node 22.12 or later and is incompatible with the accepted Node 20
  toolchain; forced Forge downgrades were not accepted. Reachability and update
  triggers are recorded in
  [`dependency-security.md`](../../operations/dependency-security.md).
- `npm run make:mac`: passed under the required toolchain.
- Svelte and TypeScript checks: passed with zero errors and zero warnings.
- Automated tests: passed, 12 files and 47 tests.
- Vite production build: passed; the metadata worker was emitted separately.
- Electron Forge packaging and DMG creation: passed for `darwin/arm64`.
- Packaged ASAR inspection: contains `dist/index.html`, the emitted metadata
  worker, `electron/main.cjs`, and `electron/security.cjs`.

## Manual verification still required

The DMG was not copied into `/Applications` or launched as part of this build
task. Before treating it as an installed, transferable release, complete the
installed-app smoke test in
[`macos-packaging.md`](../../operations/macos-packaging.md), including launch,
folder selection, navigation, metadata, zoom and pan, fullscreen, map and
offline behavior, quit/relaunch, and confirmation that source photo checksums
remain unchanged.

The artifact is ad-hoc signed and not notarized. It is suitable for trusted
local testing on Apple silicon; normal distribution to other Macs still
requires Developer ID signing, notarization, and compatible-hardware testing.
