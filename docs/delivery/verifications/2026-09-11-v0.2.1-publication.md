# Memory Atlas 0.2.1 publication verification

**Date:** 2026-09-11
**Status:** Public download verified; prerelease subsequently withdrawn for security refresh

The owner reported successful local testing of the installed 0.2.1 app and
cleared the remaining checklist. Explicit observations included startup, the
custom icon, zooming, panning, restoring zoom levels, captions and their toggle,
and correct map behavior. Fullscreen entry/exit in both layouts and Escape
priority were previously confirmed. These are owner observations, not automated
UI results.

The [final candidate record](2026-09-08-v0.2.1-final-candidate.md) preserves the
2026-09-08 automated gate and exact binary identity. The annotated `v0.2.1` tag
points to `074ac8b485d666da074fd4cbb4e6dcddfffc9334`, the clean source used to
build that artifact. Later documentation commits do not change the binary.
Synthetic smoke-test source checksums were verified unchanged on 2026-09-11.

The release is Apple silicon (`arm64`), ad-hoc signed and unnotarized; Developer
ID signing and notarization (Gate C) remain deferred by the accepted decision.
The release gate's September 8 audit passed with zero production findings and
27 accepted build-tool findings; this is dated evidence, not a fresh audit.

## Final security review and withdrawal

The final push reported 17 open Dependabot alerts, up from the previously
reviewed set. Inspection identified a critical runtime advisory,
[GHSA-jrc7-96c5-q579](https://github.com/maplibre/maplibre-gl-js/security/advisories/GHSA-jrc7-96c5-q579),
published September 8 at 20:50 UTC, after the release gate. The advisory affects
MapLibre's HTML attribution sanitizer through 6.4.0 and identifies 6.4.1 as the
fix. Memory Atlas consumes an external map style with attribution, so the
vulnerable path cannot be dismissed as unused. No exploit was observed.
Additional alerts cover Vitest/mocker and extract-zip development paths.

The release was returned to draft on September 11. Its source tag and exact
artifact were preserved; no bytes or version were silently replaced. Gate B
is reopened under the plan's new-advisory stop condition. Refresh dependencies,
review a fresh audit baseline, and build a new patch version before offering a
replacement download. The September 8 zero-production-audit result remains
historical evidence only. Owner interaction results and the matching public
download checksum remain valid observations of this withdrawn artifact.
