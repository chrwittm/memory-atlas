# Image assets

## `earth.jpg`

Provisional Earth visual for the Memory Atlas entry screen. In the Vite
application it will be available as `/images/earth.jpg`.

The embedded JPEG description identifies the scene as an Earth view captured
from the Orion spacecraft by NASA astronaut Reid Wiseman. The repository does
not yet contain a separate source URL or license record. Verify and record the
asset's source and reuse terms before public distribution.
